# 决策类别对照（现行五类 / 目标态八类）

> **地位**：ledger 对照，不是现行规格。`technical-design-and-knowledge.md` §3 的五类仍是强制升级清单。目标态八类来自未激活蓝图 [`target-doc-system-spec.md`](./target-doc-system-spec.md) 的 R7，不写入规格正文。
> **谁能改**：走任务卡。本表不授权把八类替换五类。

| 现行五类（强制升级） | 目标态八类（R7，未激活） | 对照 |
| :--- | :--- | :--- |
| `irreversible` 一旦上线无法回滚 | （八类里没有同名一条；不可逆操作在红线 RL-3） | 现行五类覆盖「上线后无法回滚」。蓝图把它放在红线，不在这八类里 |
| `costs_money` 付费或账单 | （八类里没有同名一条；外部服务与收费在红线 RL-4） | 现行五类覆盖付费 SDK。蓝图把收费放在红线 |
| `security` 认证、授权、加密、密钥 | 数据与密钥 | 密钥与认证在现行 `security`。蓝图把数据与密钥收成一类 |
| `external_service` 新增第三方运行时依赖 | （没有同名一条） | 现行五类单独弹「外部服务」。蓝图未把这一类放进八类 |
| `data_deletion` 删除或不可逆变换用户数据 | 数据与密钥 | 删数据在现行 `data_deletion`。蓝图并进「数据与密钥」 |
| （现行不单列） | 范围变更 | 现行用写范围和预算熔断挡住，不是这五类之一 |
| （现行不单列） | 已确认条目修改 | 现行用受保护条目和补丁引擎挡住，不是这五类之一 |
| （现行不单列） | 边界外文件 | 现行用网关写范围挡住，不是这五类之一 |
| （现行不单列） | 估算超档 | 现行用预算三维熔断挡住，不是这五类之一 |
| （现行不单列） | 依赖新增 | 现行在设计步骤里弹「需要装新库」，不是这五类的名字 |
| （现行不单列） | 验收标准放宽 | 现行没有对应的强制升级类 |
| （现行不单列） | 规则自修改 | 现行改规格走任务卡，没有这一类强制升级 |
